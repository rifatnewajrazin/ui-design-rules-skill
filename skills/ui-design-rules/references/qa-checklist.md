# QA Checklist Before Showing UI Work

Run it, then show the evidence.

- [ ] Every spacing value is on the scale (4px or the project's tokens). Search the CSS for stray values.
- [ ] One primary button per screen. Labels say what happens.
- [ ] Touch targets are at least 44 x 44.
- [ ] Icons use the allowed sizes and follow text colour.
- [ ] Text contrast is at least 4.5 to 1 in every state, including hover, focus and disabled.
- [ ] Keyboard: every control can be reached and has a visible focus ring.
- [ ] Looks right at desktop width (about 1440) and phone width (about 390). Check in between too.
- [ ] No horizontal scroll on a phone.
- [ ] Images have alt text. Decorative ones are hidden from screen readers.
- [ ] Nothing was added that was not requested.
- [ ] Full-size screenshots taken, not thumbnails.

Report what you checked and what you did not. Wait for a clear yes before anything goes live.
