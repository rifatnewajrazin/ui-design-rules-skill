# Naming

- Component files and their CSS classes use kebab-case: `price-card.css`, `.price-card`.
- A variant adds a plain hyphenated word: `.price-card-featured`.
- Names describe the function, not how it looks or where it sits. `.alert-banner` ages better than `.red-box-top`.
- Keep names short. If a name needs four words, the component is probably doing too much.
- Icon names describe the object (see `icons.md`).
